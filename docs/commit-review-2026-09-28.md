# 提交前代码 Review

范围：本次累计功能改动，重点追踪网页草稿、MCP 共用服务、版本/幂等、保存恢复、检查投影与模板金额链路。审查方式为源码追踪及隔离回归；不是逐文件穷举审计，也不是安全专项扫描。

## 发现并修复

1. **新建项目首次保存受阻（P1）**：网页从正式版本 0 建立草稿后，`list_check` 尝试读取不存在的历史版本 0，返回“项目没有保存版本”。改为使用空配置作为版本 0 比较基线，首次保存仍执行项目版本检查。回归验证首次检查、保存为 v1、同幂等键重试不增加版本。
2. **保存重开丢失用途待办（P2）**：读取历史项目时仅补处理动作，却先过滤了已有 assignment 检查；结果是待确认状态仍在，但具体待办消失。只读补充模式现在保留已保存的用途问题和处理入口，不改写历史快照。回归验证保存、重开后仍能关联设备用途。
3. **Excel 重算掩盖过期说明（P2）**：项目说明绑定旧型号时，系统报价总计为待确认，但导出公式仅检查价格和供货，Office 重算可能显示完整总价。模板现在复用业务层的说明版本判断，以保存修订中的配置核对，过期说明保持待确认；不解析错误消息，不向旧快照追加新字段。

三项均先用回归测试复现失败，再修复。新增用例见 `backend/tests/configuration/test_review_regressions.py`。
