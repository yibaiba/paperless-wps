# Univer 开源工作表实施记录

## 接入与使用

项目配置 → 报价与模板导出已经内嵌 Univer。`@univerjs/core`、`@univerjs/presets`、`@univerjs/preset-sheets-core` 精确锁定为 1.0.2；没有 Pro 包、Univer Server 或 Office 服务依赖。工作表及其 CSS 只在打开报价视图时加载。

- C 列部署数量、D 列单价、E 列报价分区、F 列备注可编辑；灰色列是业务投影。
- 矩形文本粘贴进入预览；含单价的修改需提供共同依据，检查后整批应用。任一单元格不合法，不部分提交。
- 选区支持多行；上方可批量调整所选设备的单价。
- 右侧显示设备 ID、来源工作表/行号、价格依据、服务系统、原始参数和报价问题。可打开原有价格、供货和候选组件。
- 换型保留设备 ID、数量及系统引用，显式重新选择供货来源；原单价绑定不会自动变成新产品价格。
- 排序、列宽、缩放只影响当前工作表。排序后编辑依然按设备 ID 应用，重开恢复默认布局。
- 工作表、项目工具栏、清单与图纸共用项目撤销历史。键盘撤销通过 Univer 的 BeforeUndo / BeforeRedo 接管；编辑单元格文字期间仍保留文字撤销。
- 金额由现有 Python Decimal 报价服务产生；不允许用单元格公式覆盖。数量增加不会擅自增加采购分配，缺价仍是待确认。

## 共享服务

`configuration/projects/services/editing.py` 从 MCP 的命令实现抽取为共享业务服务，`lists/commands.py` 保留导入兼容。新增窄操作 `device_patch`、`section_set`，避免为单个单元格提交新的设备快照。

`POST /api/configuration/projects/{project_id}/edit-preview` 接收当前 Configuration、expected_revision、draft_version 及 operations。整批校验后调用原项目检查、配套、图纸和报价投影，返回 checked 与 changes；不保存项目修订。失败操作返回 operation_index、设备 ID 和原因。

工作表应用返回结果前核对草稿版本、保存版本、预览输入代次；修改依据会使旧预览失效。草稿撤销即使回到同样内容，也不会接受旧异步返回。批次只有整批应用时进入一次项目历史。

检查结果在当前编辑会话按业务配置缓存，撤销/重做到已检查配置时恢复对应金额与检查。未检查的跨视图修改仍明确显示结果过期，不冒充重新计算。

候选接口仅在显式全部产品模式允许没有系统/角色的目录浏览，这些结果一律资料不足；按角色筛选仍要求有效上下文。

## 验证

使用独立 SQLite 数据库及随机 PostgreSQL 测试 schema，没有向业务产品或项目写入测试知识。

已完成：

- 后端编辑预览原子性、设备 ID 不存在、非法数量/快照字段、供货缺口、Decimal/零价、换型旧价失效、保存冲突及 HTTP/MCP 同语义。
- 现有配套、独立/共享服务器、容量和资料不足回归。
- 真实 stdio MCP 查询、编辑、检查、保存、导出与进程重启回归。
- PostgreSQL 重试幂等和竞争写入测试（单独提供 TEST_DATABASE_URL，测试自动创建/清理随机 schema）。
- 六项前端适配测试：排序身份、多行/引号粘贴、精确小数与零价、只读与无效输入、价格来源/过期绑定、过期请求。
- TypeScript 检查和生产构建。构建仍提示 SDK 分块较大，工作表代码已按需加载；未屏蔽该警告。
- 真实浏览器：单格编辑、矩形粘贴、缺依据不能应用、整批撤销/重做、跨视图同步、分区排序后的正确设备修改、只读列拒绝粘贴、公式数量被拒绝、无角色设备换型及旧价失效、保存重开和导出；⌘Z / ⌘⇧Z 快捷键复验通过，格式快捷键不会清空业务字段。
- 浏览器保存隔离项目 v3 后，真实 stdio MCP 读回报价合计 45.31。采购 2.5 × 单价 18.125，逐行四舍五入；客户已有设备采购数量为零。
- 导出工作簿保留 1 个 Logo、合并单元格、ROUND 金额公式、税运说明和 45.31 缓存结果。原模板 SHA-256 未改变。动态扩行及长说明沿用现有报价回归测试。

后端每项设置 pytest timeout=60，测试批次外层 subprocess timeout=60。前端构建设置 120 秒超时。

本轮没有进行桌面 Excel/WPS 的实际显示与重算验收；文件结构/公式/缓存值验证不等于该项已通过。Word 编辑、任意 XLSX 导入、自由改变业务公式不在本轮范围。

## 验证命令

```sh
node --test --test-timeout=60000 frontend/tests/quotation-sheet.test.mjs
```

后端测试通过脚本包装 pytest，必须同时设置单项及批次超时。生产构建在 frontend 目录运行 `npm run build`。
