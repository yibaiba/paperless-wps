# Univer 加载与增量编辑验收（2026-09-28）

## 交付结果与边界

已消除 `QuotationSheet → SheetEditor` 两层串行懒加载；外层仍按需加载，鼠标进入报价页签、键盘聚焦页签及实际打开共用同一个模块 Promise。预加载不挂载组件、不创建工作簿、不调用报价或编辑接口。

工作簿通过初始 `cellData` 填充一次。后续投影按设备 ID 和当前位置比较字符串值，只有变化时才执行一次稀疏写入。行数未变时不调整行数，删除的尾部数据清除，新增区域设置样式；程序写入清除公式及富文本残留。SDK 返回失败时停止表格编辑并明确报错，成功后才推进快照，没有整表重建兜底。

同项目切换页签保留实例；离开项目释放事件订阅及工作簿。删除选中设备后清空详情，撤销能恢复。加载失败限定在工作表区域，其余项目页面和草稿仍可用。

依赖和 Univer 1.0.2 插件组合未改；本轮未修改后端业务、MCP、数据库及正式部署配置。没有包体积减重结论。冷启动时间有明显波动，**尚不能认定冷启动在所有场景稳定变快**；编辑投影减少已由 SDK 调用计数及真实浏览器操作验证。

## 测量环境与口径

- 同一台本机、同一 Codex 内置浏览器标签、相同视口与本机网络；Vite 生产产物分别在 5178（原实现）和 5179（优化）提供。
- 独立后端 8017 使用 `data/verification/univer-performance/browser.sqlite`，创建 100 / 500 设备隔离项目，使用真实检查、编辑、保存和导出服务。未写业务数据库。
- 原实现仅加入相同测量代码，原源码副本、原构建、优化构建、JSON 和截图保留在 `data/verification/univer-performance/`。
- 页面冷启动测试请求开发工具关闭 HTTP 缓存并重新导航；不是新启动浏览器进程，不能排除 JIT、操作系统缓存和其他页面调度影响。最后一次资源记录存在 `transferSize=300`，不能将这些记录等同于完全清空所有缓存的独立浏览器冷启动。没有网络限速。
- 诊断构建显式设置 `VITE_SHEET_PERFORMANCE=1`。普通生产构建关闭测量。只记录阶段、时间、行数、写入次数和单元格数，不记录客户、产品、价格或设备 ID。
- `initialize` 是创建 SDK 实例及工作簿的同步时间；`rendered` 从初始化开始到 Univer 的 Rendered 生命周期事件，包含初始化，**两列不能相加**。实际可见内容另由截图与首次编辑验证。
- `edit-request` 包含 HTTP 往返和业务计算；`projection` 为前端比较、SDK 写入及快照处理，不是完整编辑响应时间，也不包含随后浏览器绘制的全部时间。

- 自动测试：投影与工作表纯函数共 **14 项通过**。覆盖 500 行单格变化、相同数据零调用、同型号不同 ID 排序、尾部残留清理、跨最低行数边界、SDK 写入/调整行数失败抛错、十进制原文、零价和缺价、只读列、非法公式、批量纠错和过期响应。
- 后端已有回归：`test_sheet_edits.py`、`test_quotation_details.py`、`test_list_mcp.py`，**16 项通过，7.53 s**。pytest 每项 `--timeout=60`，外层进程每批 `timeout=60`。覆盖网页与 MCP 语义一致、供货不自动推定、换型价格过期、原子编辑、并发版本、保存历史、金额和模板导出。
- TypeScript 检查通过；诊断生产构建和关闭诊断的普通生产构建通过，命令均设 60 秒超时。未修改依赖；构建仍提示大 chunk，属于本轮保留完整插件组合的已知限制。

- 真实浏览器：键盘撤销/重做、工具栏撤销、跨视图删除/撤销恢复、100→99→100 行数、删除选中对象清空详情、按报价分区排序、排序后修改备注、页签复用均通过。普通单格修改未重建实例或重设列宽/缩放。
