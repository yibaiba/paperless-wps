## 1. 售前闭环

### 工作草稿

- 网页首次业务修改建立独立 `list_draft`，地址栏携带 `draft` ID。工作草稿与正式项目版本分开，自动同步不发布正式版本。
- URL 恢复和项目草稿列表提供显式恢复入口；展示来源、基线及更新时间，不自动合并多个草稿。
- 串行写入带预期修订和幂等键。网络结果不确定时，重试原请求；422 错误允许修正后重试，409 明确报冲突。
- 未同步修改受到侧栏、返回和浏览器关闭保护；已同步草稿可离开。同步失败保留页面内容。
- 当前会话撤销、重做使用服务端修订检查点；重新打开恢复最新草稿，不恢复上一会话的撤销历史。
- 正式保存复用 `list_check` 与 `list_save`，执行完整检查及项目基线校验。撤销草稿不会回滚已经发布的正式项目基线。
- 图纸和配置一起恢复；单纯图纸变化不计算采购和报价。

新增 `/api/work-drafts` 查询/创建、`/{id}` 完整恢复、`/{id}/edit`、`/{id}/preview`、`/{id}/restore`。原 HTTP/MCP 工具名称和旧 `edit-preview` 保留。

### Excel 业务归属和处理入口

- 字段/产品确认后增加业务归属步骤，支持批量指定系统、创建本批房间和系统、指定已有角色或新增角色，也允许待关联。
- “新增设备”和“关联已有设备”明确分开。关联已有设备仅建立用途，不采用导入数量、价格或描述覆盖已有设备。
- 同型号不同设备继续保持独立 ID；一批导入对应一次预览、应用和撤销。
- 检查返回结构化动作，页面按对象 ID 打开候选、供货、用途、角色资源、配套或知识入口；不解析提示文本决定跳转。
- 数量输入明确标为部署总量，供货单独核对；未分配设备形成待办，不能因为没有角色检查就认为通过。

## 2. 编辑与性能

### 共享服务

网页、表格、导入与 MCP 共用编辑操作和检查服务；前端将旧表单修改转为业务操作，产品和来源快照仍由服务端产生。

轻量编辑复用可信服务端上一次检查：

| 编辑 | 执行内容 |
| --- | --- |
| 备注、说明、分区 | 更新输出和相关投影，不执行完整搭配检查 |
| 单价、价格字段 | 更新报价及价格问题 |
| 供货 | 更新供货、采购及报价 |
| 产品、数量、角色、资源、配套 | 完整检查 |
| 图纸布局 | 仅配置中的图纸视图 |

设备、产品、来源与历史修订批量读取；同请求复用固定版本目录。目录延迟加载，备注修改不读取整份产品目录。

后续网页编辑返回按设备 ID 的变化字段及检查投影差异，不返回完整知识快照。删除/排序返回新顺序；其他设备对象保持引用。Univer 继续稀疏写入。
