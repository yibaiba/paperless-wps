# 本地 draw.io 图纸工作台

2026-09-24。拓扑画布改为官方 `jgraph/drawio:29.6.5` 完整编辑器，业务表格/表单继续使用 Ant Design。已移除 X6 及其额外 tslib 依赖。没有另写画布引擎。

## 启动与访问

在项目目录运行 `docker compose up -d diagrams`；首次需要下载镜像。绘图容器使用本地 8086 端口，工作台通过 `/diagram-editor/` 代理访问，浏览器仍只访问 5176。开发和预览服务均配置了此代理。生产部署也需要代理 `/api/` 和 `/diagram-editor/`，并把 Compose 的 `DRAWIO_SERVER_URL` 改为实际工作台地址。容器不保存业务图纸，图纸保存在现有 PostgreSQL 中。

编辑器使用本地资源和嵌入模式，容器的云存储集成未启用，没有将产品或图纸上传到 diagrams.net。高级云端转换服务未配置，不能据此声称已经支持全部 Visio 文件转换功能。镜像及附带图形遵循各自上游许可；本次未安装第三方音视频图形包。

## 使用流程

- 「专注画图」展开工作区。左侧为通用、网络设备、机柜、电气图形库，右侧调整样式。可使用原生直角连线、缩放、对齐、页面和撤销/重做。
- 「添加产品」从已导入 Excel 中选来源记录，选择终端、主机、交换设备或机柜的示意外观，加入主图。外观是示意符号，不代表真实型号接口或尺寸。
- 也可先拖入原生图形，在「未绑定图形」中选择该图形并绑定产品；原有形状、配色和旋转保留。文字和装饰图形可保持未绑定，不计入设备清单。
- 「添加系统区域」建立房间/系统。产品所在区域来自图中父分组；也可在「产品与规则」修改放置分组、角色、数量及额外服务系统。
- 连接两个已绑定产品的图形后，普通连线进入业务面板，初始为待确认。可编辑为必配、可选或接口接线关系。没有连接两个产品的普通线条只用于绘图。
- 保存方案，持久化完整 XML、产品快照与业务数据。在「产品与规则 → 设备清单」查看保存版本的汇总，在「关系」生成草稿规则。

设备/关系的数量语义、共享不重复计数、草稿启用条件与原有拓扑规则一致，见 [拓扑规则说明](topology.md)。

## 数据一致性

- `drawing_xml` 是新图纸的唯一业务数据来源，后端重新解析数量、分组和连接端点；客户端同时提交的旧数组不能覆盖图纸内容。
- 原有 JSON 方案打开时转换为图纸，原节点及关系 ID 保留；第一次保存才新增 XML 版本。旧历史不改写，已生成规则的关系关联不丢失。
- 原生形状、样式、连接拐点、图片与页面随 XML 保存。支持未压缩页面及 draw.io 的 Base64/Deflate 压缩页面。
- 页面内图形 ID 对应业务节点；其他页面使用页面 ID 和节点 ID 生成 URL 安全标识，避免复制页面时设备 ID 冲突。
- 已标记的业务关系脱离产品节点、产品来源失效、非正数量和无效 XML 会明确报错。未绑定图形和普通连线会在界面单列，不伪装成完整清单。
- XML 使用 defusedxml 解析；消息验证发送窗口及来源。产品标签通过 XML 属性写入，未直接拼 HTML。
- 业务配置使用本地 draw.io 插件入口注册适配器，启用官方内置 `props` 插件以初始化插件入口，再通过 `diffPages` 和 `file.patch(..., undoable=true)` 应用本地编辑，并读取编辑器实际 XML。未使用会用旧本地值解决冲突的远端 merge。此适配依赖固定 draw.io 版本，升级镜像必须复测绑定、数量、复制、撤销、保存。
- 图纸语法检查有短暂合并延迟，但保存始终直接提交最新 XML，由后端完成验证；有修改时不能用旧保存版本生成规则。

新增 `POST /api/topologies/drawing`，用于检查图纸或应用产品/分组/关系操作，不写数据库。原有保存、历史、规则接口保留。

## 当前边界

本次实现绘图与产品规则数据的连接。产品页图片/PDF 自动识别、型号级物理端口校验、线材长度/数量自动计算、跨系统容量分配和完整报价生成仍未实现。一个图形绑定一条产品来源记录，一组相同配置设备用数量表示。其他页面的设备可关联额外服务系统；物理连线仍在同一页建立。

- 浏览器实测：设备图库拖入后识别为未绑定；绑定真实 PCS-1516N 后节点数从 2 变 3；撤销绑定及图形后回到 2。数量 1→2→原生撤销回 1；图纸和产品面板一致。保存 v6、重新打开、查看原 v4 生成的规则关联均通过。
- 验证了宽屏工作区及默认窄屏，已恢复浏览器正常尺寸。保留无纸化示例：两款原产品各 1、1 条必配关系、v1—v6 历史。临时验证图形未保存，没有启用规则。

原生远端 `merge` 曾在验证中造成新产品绑定被旧值覆盖，已改为可撤销的本地 patch 并复测。开发热更新切换适配器时出现的旧 hook 清理异常，通过完整重载新代码消除；以上最终浏览器验证是在新适配器完整载入后完成。

### 产品多选与连续添加（2026-09-24）

产品侧栏支持勾选、全选本页、清空选择以及跨页/搜索保留勾选；切换产品库时明确清空选择。点击“添加所选产品”一次加入整批产品，完成后清空已提交勾选并保持侧栏打开。单个“直接添加”也保持打开。绑定现有图形仍为单选，成功后关闭绑定栏。失败在栏内显示原因并保留选择。

`add_products` 操作先验证整批来源，再生成一份 XML，通过原生一次可撤销编辑应用。按选择顺序四列排开，放在第一页现有图形下方，每个节点初始数量为 1。接口拒绝空选择、重复来源和不存在的来源，不产生部分添加。
