# 方案拓扑规则与第一版记录

> 界面现已升级为 [本地 draw.io 工作台](drawio.md)，下方 X6 使用和验证记录属于升级前版本；业务规则语义继续保留。

2026-09-24，使用 AntV X6 3.1.8 与现有 Ant Design。入口 `/topologies`。

## 使用

1. 新建拓扑，填写名称、维护人；从已导入 Excel 的产品库搜索记录，点击添加或拖入。
2. 添加系统分组，可明确填写方案产品线。双击设备或在设备表编辑：角色、数量、放置分组、额外服务系统及条件。
3. 从连接点拉线，或使用「添加关系」表单。关系分为待确认、必须搭配、可选搭配、接口接线。
4. 必配关系填写数量模式、参数和依据。接口接线填写两端接口、线材和实际长度；不会按画布距离推断线长。
5. 保存后可查看设备汇总、版本历史。必配关系可单独生成草稿规则，去配套规则页面检查、试算后再启用。

X6 负责真实画布拖拽、连接、缩放、框选、对齐辅助线、分组缩放和撤销重做。没有自行实现画布引擎。产品栏用 Ant Design 和 X6 Dnd；设备使用 X6 内置矩形节点。只新增 `@antv/x6` 及其打包输出所需 `tslib`，未使用 React 节点适配包。

## 语义与边界

- 一个设备节点代表一批相同产品来源记录，设备数量与画布位置分别保存。
- 分组是方案中的房间/系统，不会修改原产品库的产品线标签。同一产品可用于不同方案。
- 共享设备用一个节点加多个服务系统表达，设备清单只计入节点本身数量；不同节点仍代表不同批次设备。
- 设备清单按来源产品 ID 和所在分组合并，用 Decimal 汇总，不合并不同来源的同型号。
- 界面连接点是关系操作点，尚未建立型号级物理端口库，不代表已经验证的接口。
- 可选、接线、待确认关系只记录，不自动增加设备、线材、价格或计算兼容性。
- 仅同组、非共享的必配关系可生成草稿，因为现有规则引擎按项目组计算，不能将跨组共享关系当成同组配套。
- 生成的是全局草稿规则，**不限定原拓扑或分组名称**。启用前核对适用范围；与已有规则重叠时也需要维护人处理。
- 同一拓扑关系只能生成一次规则；之后编辑/删除拓扑关系不修改或停用已生成规则，关联记录保留生成版本。
- 保存时留存产品来源和属性快照、维护人、完整图数据；历史版本只读。新产品库版本不会自动替换图中产品。
- 仍然没有产品页图片/PDF 参数自动提取、自动选型、跨系统容量分配、线材清单自动计算或直接生成项目报价。
- 本地开发环境，维护人是手填记录，不是登录身份。

## 数据与接口

新增表：`topologies`、`topology_revisions`、`topology_rules`，启动时按现有方式建立。旧产品、项目、规则记录不改写。

- `GET/POST /api/topologies`
- `GET/PUT /api/topologies/{id}`
- `GET /api/topologies/{id}/history`
- `POST /api/topologies/{id}/relations/{relation_id}/rule`

保存和转换都校验版本，并对拓扑行加锁。规则与拓扑关联在同一事务提交；新增唯一约束防止重复转换。规则仓库新增可选 `commit=False`，原有调用默认行为不变。
