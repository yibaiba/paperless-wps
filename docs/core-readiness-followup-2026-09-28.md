# 核心业务复查与修复

本轮直接修复可复现的软件错误，不将缺失的授权、容量或共享资料补成确认结论。没有修改业务库、真实项目或产品资料。

## 已修复

### Excel 合并备注遗漏

报价导入接口保留原始单元格，增量返回合并区域坐标。读取继续采用流式单元格解析，合并信息使用已有 defusedxml 依赖解析；不执行公式。

前端只将表头之后、纵向单列的备注投影到覆盖的明细行。核对表显示共享备注范围，导入依据保留工作表、原行和合并区域。数量、单价、横向合并或跨列内容不自动复制；原始行始终保留，用户仍可修改备注或取消明细。

“选配”备注不自动成为知识规则，不自动取消采购；采购仍由用户核对本次导入行决定。剪贴板文本本身不含合并信息，无法据此恢复 Excel 合并区域。

### 导入角色引用失效

已选角色不存在，或角色引用没有所属系统时，明确定位到原表行报错；不再悄悄成为待关联设备。新增设备和关联已有设备两条路径均覆盖。整批仍先预览后应用，无部分提交。
