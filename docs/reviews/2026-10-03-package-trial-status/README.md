## 验证

- `npm run build`：TypeScript 检查及生产构建通过，命令使用 60 秒进程超时。构建仍有既存的报价工作表大包提示，完整输出见 `frontend-build.txt`。
- `pytest tests/configuration/test_package_trials.py --timeout=60 -q`：13 项通过，4.87 秒；整批另设 60 秒进程硬超时。
