## 实施结果（2026-09-27）

新增能力与操作说明见 [核心业务使用及架构](core-business-evolution-guide.md)。原计划保留当时状态，本文件记录实施结果。

### 业务与版本语义

- 新项目默认计算版本 3，旧版本 1/2 保留原路径。新版知识不能被旧算法静默执行；升级通过变更预览。
- 新版知识的关系确认与数量确认分别维护；空范围、空公式或空系数均保持未知。环境数量必须使用一致单位，结果包括输入、配置修订、来源、规则修订和实际 ZEN 表达式。
- 启用条件与兼容约束分开；显式替代组用“任一分支”，独立约束共同满足，禁止事实不能被推荐抵消。可选项未选不产生需求；选中后参与完整检查。
- 系统、角色、能力使用稳定身份。已发布知识包固定角色定义和成员修订；更新成员不改变已发布包。旧文本映射必须显式预览、应用，生成草稿定义，不自动确认业务。
- 批量变更预览并校验修订，单事务应用，幂等记录用唯一约束处理并发。过期批次整批回滚，同一请求重试不重复创建。
- 产品、知识、系统定义和包更新提示版本差异，旧项目检查仍用原快照。已知检查、资料覆盖、可确认状态、人工确认具体修订分别记录。
- 新设备及新增配套明确选择供货来源；同一设备可拆成已有、采购、待定分配。已有设备留在部署/图纸中，只采购明确采购的数量。
- 检查计算不删关联、不改输入；关联清理通过预览应用。变更比较覆盖设备、需求、供货、选配、资料及采购差异。

### 代码与存储边界

仍是 FastAPI 模块化单体，不增加运行依赖、AI 决策或新服务。

- `configuration/definitions`：系统/角色定义、能力、知识包修订与旧文本映射。
- `configuration/knowledge`：统一维护、批量预览、结构化出处和条件语义。
- `configuration/projects/calculation`：版本 3 纯计算，配套、覆盖、供货、共享与资源检查。
- `configuration/projects/services`：固定资料快照、配套应用、变更用例、确认项目修订。
- `configuration/projects/projections`：差异、旧清单投影；版本 3 设备内部 ID 按项目命名空间保存，旧 API 继续返回原设备 ID，修复不同项目同设备局部 ID 冲突。
- `configuration/http.py`：错误映射及 ZEN 依赖注入入口，其他路由不再从旧规则路由引入依赖。
- 前端 `knowledge/` 与 `projects/`：分离工作台、定义、知识包、供货、确认、变更和请求状态；原路径及 Ant Design/draw.io 保留。

本轮复用现有实体/修订表增加实体类型和 JSON 字段，不新增数据库表，不重建数据库。生产应用没有执行旧文本映射或写入测试知识。

新增合成数据测试在独立临时库验证两台独立服务器、共享一台、共享依据缺失、已确认共享/资源通过、容量超量、客户已有不采购、重复应用、取消配套和删除恢复。测试数据均标注隔离测试，不构成真实产品确认。

真实资料副本用随机 `evolution_pilot_*` schema，保留来源及同型号配置的独立 ID：红盾表第 8 行 RS-MSC100（Windows）、会议预约表第 18 行 CRIR-GL20S（Linux）、第三方表第 3 行 NF5280M5。没有推断跨系统共享或补写容量需求。

真实浏览器已验证：

- 同型号不同来源配置独立展示；产品视图录入数量未知草稿可保存。
- 旧文本映射预览/应用只产生草稿定义。
- 共享服务器为 1 台并显示两个系统用途；改为客户已有后采购只保留两项软件。
- 变更预览、应用、撤销、重做、保存、重开保留供货状态。
- 图纸添加同设备引用不增加设备或采购数量，实际 draw.io 可显示该设备。
- 复制为新设备需选择供货来源，明确采购后只增加该副本的采购；一次撤销同时恢复设备、供货和图纸。保存后同步清除内嵌编辑器的修改状态，浏览器重开成功。
- 截留真实检查响应期间编辑草稿，返回后明确提示过期，不覆盖新编辑；网络失败明确报错，恢复后可重试。
- 缺真实共享依据时无法点击人工确认；待确认项定位产品或知识。

前端 TypeScript/生产构建通过；Vite 仍提示共享依赖块约 624KB，这不是构建失败，也不代表已完成大规模前端性能优化。后端测试有既有 Starlette/httpx 弃用提醒，本轮不为消除提醒更换依赖。

## 性能测量与边界

本机 TestClient + PostgreSQL 隔离副本，3 次采样；242 个配置、201 条原知识（副本映射后有修订）、一个房间/两个系统/四台部署的独立方案。无网络传输延迟，不是压力测试。

| 操作 | 范围 | SQL 次数 | 响应大小 |
| --- | --- | ---: | ---: |
| 候选（固定快照，实际返回 3 项） | 338–450ms | 6 | 39.6KB |
| 检查 | 178–202ms | 40 | 420KB |
| 保存 | 270–326ms | 47 | 420KB |

检查产品读取已按所选配置 ID 批量加载，避免每次加载整库；知识仍在响应中携带完整快照以保持现有协议。前期检查单次约 594ms，但采样轮数、进程预热及数据修订不同，不能当作严格性能提升比例。早期候选采样返回空结果，已排除，不作为性能基线。

收尾核对业务 schema：459 条来源、201 条知识、0 个项目，与开始时相同。隔离副本的项目、草稿和映射不出现在业务库。真实客户项目、软件授权资格及共用容量未验收；正式报价、偏离表、音视频完整接线与定制制造仍不在本轮范围。
