# 产品属性与规则复用

日期：2026-09-24。

规则现在支持以产品属性确定触发范围。可复用规则例子：本产品库版本中，系列包含“S系列”、功能包含“话筒升降”、适用系统包含“分布式无纸化会务系统2.0”的所有配置，检查是否配有指定会议主机。

## 使用方式

1. 产品资料库打开具体来源记录，进入“规则属性”，维护系列、功能、接口/协议、适用系统，填写依据与维护人后保存。每个字段支持多个值。
2. 也可以勾选多条产品，点击“批量维护属性”，对某个字段增补或移除指定值；其他字段和原始 Excel 内容不变。跨页选择支持保留；切换来源版本会清除选择。
3. 编辑配套规则，将“触发范围”切换为“按产品属性匹配”，添加条件。每行条件都必须满足；行内可选“包含全部值”或“包含任一值”。
4. 点击“预览匹配产品”核对具体来源、数量和单位。特殊配置可放入“例外”排除列表。
5. 保存后，同一来源版本内产品补齐属性或修改属性，会自动加入或退出匹配。规则定义和版本不需要因为成员变化而逐一修改。

属性按完整文本精确匹配，会去掉输入值两端空格，不做近义词、型号前缀或自由文本推断。“S系列”和“S系列扩展”不是同一值。建议批量维护同组产品，统一写法。

零匹配会明确显示0条，项目中不会计算为全库匹配。未填写属性的产品也不会凭名称被猜测为符合条件。

## 历史与修改影响

- 属性独立保存到 `product_attributes` 和 `attribute_revisions` 两张新增表；现有产品来源 payload 和项目快照不改写。
- 每次保存记录完整属性、修订号、维护人、依据与时间。单条和批量都检查旧修订号；批量操作原子提交，某条冲突则整批不写入。
- 属性保存与规则应用锁定相同来源产品，避免应用过程使用一半旧属性、一半新属性。首次并发维护同一条属性只允许一条成功，另一条返回409。
- 项目预览摘要包括匹配来源及属性版本。影响匹配或匹配依据的属性变化后，旧预览不能应用，需要重新计算。
- 规则版本历史保留保存时的匹配来源和属性快照；应用记录保留实际计算时的属性版本、条件及每个来源贡献数量。不会用今天的属性重解释过去的应用记录。
- 若修改属性使已启用规则匹配到了自身配套或混合计量单位，列表会明确提示条件需修正；相关项目计算返回明确错误，规则仍可打开编辑，不隐藏异常或输出伪成功结果。

## 真实资料整理

已依据分布式无纸化会务系统2.0的 A34:A49、产品名称和完整参数，整理16条 S 系列配置：

- 16条都有系列“S系列”和功能“屏幕升降”。
- 其中8条名称含“带话筒”的配置增加功能“话筒升降”；其他8条不增加。
- 参数明确说明RS485控制，接口/协议记录为“RS485”。
- 适用系统标签记录来源产品线“分布式无纸化会务系统2.0”，不代表已确认跨系统兼容。

通过实际浏览器批量维护16条记录的系列字段，并验证属性历史保留前后版本。主机必配、主席/代表模块候选两条草稿由逐个列型号改为上述三条件，各匹配8条带话筒来源记录，普通升降器不命中。

两条规则均保留v1及新的v2，仍为草稿；主机容量、模块比例、席位角色与具体适配仍需要业务确认。服务器共享和原音频规则继续使用指定型号，未凭空归纳可共享的产品属性。正式来源仍459条、资料差异31项、共4条草稿规则，没有启用正式业务规则。

## 当前边界

- 当前属性为四类多值标签。数值容量、尺寸区间、开孔公差、价格等尚未成为属性条件运算符；数量公式中的比例仍由规则维护。
- 本轮改造触发产品的范围，配套目标及候选仍绑定具体来源配置，不会自动挑选新配套型号。
- 条件绑定明确的产品库版本。新 Excel 版本不会自动继承旧版属性和规则；需要维护新版属性并调整规则来源版本，避免同型号不同配置被误套用。
- 草稿和停用规则不参与计算，属性分类本身也不是工程适配批准。

- 首次完整回归触发整组60秒超时，未计为通过；随后按常规/并发47项、无纸化资料和配置9项、无纸化规则9项分别执行，每组及每项保留60秒超时。结果为 **65项全部通过，无跳过、无预期失败**。分组耗时分别4.01、23.51、18.99秒，较慢部分是每个无纸化用例重新解析并导入真实工作簿。

- Ruff格式与静态检查通过；前端TypeScript与生产构建通过，既有大包提示和Starlette测试接口弃用提示仍存在。
- 浏览器验证了跨页勾选16条、批量保存系列、条件编辑、预览匹配8条、保存v2、属性详情及版本历史；布局在当前窄窗口可用。
