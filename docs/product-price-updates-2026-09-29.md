# 产品与价格快速维护验收

本轮使用现有 Python 模块化单体、修订存储、草稿操作、Decimal 和 Ant Design。未增加依赖、AI 调用、服务或价格定时任务。

## 可操作入口

- 产品整理 → 更新产品与价格：上传或选择新版工作簿、指定历史基准/工作表/产品范围，恢复更新草稿，逐行确认归属，或批量指定价格列、生效日期和配置。保存结论不发布；选定行先预览再发布。
- 单行编辑支持展示说明、独立配置、新产品、原参数纠错、供货状态、替代候选。复制搭配与已含内容为待核对草稿。原 Excel 保持不变。
- 报价与导出 → 检查价格更新：指定固定日期，查看新旧单价及采购差额，明确选择后采用。人工与导入价没有默认选择。采用一次对应一次撤销，沿用工作草稿、保存与导出。
- MCP 保持工具名称。`catalog_get` 可按 `on_date` 查询价格；`list_get` 的 `price_updates` 视图返回预览，`list_update` 用 `price_versions_adopt` 和预览指纹采用所选修订。

## 数据与边界

更新批次、价格槽位、影响记录复用 Entity / Revision 存储，未重建数据库。每个配置、价格列、生效日期只有一个槽位，同日更正生成修订。零价有效；不发布的列保留原状态；显式待询价停止沿用更早价格。日期按北京时间解释。

技术参数纠错记录配置修订和受影响关系修订，包含类别/系列范围关系以及配套候选，列出知识包及已保存项目。旧项目固定快照保持原结果。复核要求只作用于变更配置，关系未整体停用。新配置不自动获得复制关系的已确认结论。

报价固定保存价格修订与金额，服务端按不可变修订校验；价格来源独立于设备资料来源。只调价走现有增量报价路径。未来生效、同日修订、产品停止选用或配置参数不符都在价格预览中明确展示。
