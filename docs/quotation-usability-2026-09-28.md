# 售前报价操作体验改进（2026-09-28）

本轮从使用人员的报价改单流程检查现有页面，继续使用 Ant Design、Univer 与现有业务编辑接口。没有新增依赖或改变选型、供货、数量及报价计算规则。

## 改进

- 售前进度默认折叠，保留检查状态，可直接定位到检查与待办；保存和撤销工具栏随滚动保持可用。
- 报价合计、已知金额小计、报价问题集中展示；客户和税运资料按需展开。过期结果明确标为上次计算。
- 选中设备后，右侧显示部署、本次采购、客户已有、供货待定和金额，并提供价格、供货和换型入口。
- 批量修改预览显示产品、型号、单元格、原值与新值；可原地修正。修正后取消旧检查的应用资格，重新检查后才能整批应用。整批仍只产生一次撤销记录。
- 候选区区分没有产品与筛选无匹配，支持清除筛选，显示筛选数量；空列表和单页不显示分页，结果缩小时将页码限制在实际结果范围内。

使用 `data/verification/univer/browser.sqlite` 隔离数据库，未向业务数据库写入测试项目或价格。

- 前端 Node 测试 8 项通过，包括排序后的设备身份、批量修正不改变其他设备、原始编辑数组不变、零价、Decimal 文本和过期响应。
- 后端 `test_sheet_edits.py` 6 项通过；每项及批次均为 60 秒硬超时。
- TypeScript 与生产构建通过。Univer 按需加载的 JS 块约 6.63 MB，gzip 约 1.71 MB，构建仍提示体积较大；本轮未声称解决首次加载成本。
- 浏览器实际验证矩形粘贴、非法公式定位 C2、原地纠错、修改后预览失效、整批应用、撤销、重做、保存 v4 和重开。
