# 产品搭配维护与售前选配流程验收

日期：2026-09-29。沿用现有模块化单体、Python 判断、ZEN 数量计算、Decimal 报价及 Ant Design／Univer／draw.io。本轮没有新增运行时依赖、AI 决策或数据库重建；工作区此前已有的未提交修改保留。

## 交付内容

- 产品维护工作台支持按配置、系统及角色定位，复用基本配置、已含内容及关系编辑。快速编辑预填稳定 ID，原文资料与表单并排，可添加准确来源引用；多配置维护先显示覆盖范围与例外。
- 简单编辑合并它负责的字段，保留复杂条件、触发条件、替代分支、来源与迁移信息。复杂关系可以转入高级编辑。复制关系重置为草稿，数量确认同时重置。
- 配套关系可以确认“需要”，候选和数量继续待补；没有默认每台一个。数量输入来自注册属性与用途检查，候选、数量和容量分别显示状态。
- 知识包整理变更先预览，逐项选择成员或定义升级；旧包编辑使用固定定义及成员修订，未选择的新资料不自动加入。发布仍复用原有角色确认规则，不要求所有局部资料齐全。
- 项目“系统与需求”抽屉合并房间、具体系统版本、资料版本、功能及输入。服务端在角色尚未创建时返回输入描述，规模复用系统参数，角色环境只作用于对应角色；历史自定义输入保留高级入口。
- 按已确认定义预览必要角色，用户确认后一个原子批次建立；重复操作复用角色，关闭功能不删除设备。所有配套候选均要求显式选择，单个候选也不预选。
- 待办按需求、选型配套、供货价格、公共知识分组，保留全部检查与对象。跳转维护携带工作草稿、系统和角色上下文，返回后主动预览资料升级。
- 网页与 MCP 共用需求描述和 `system_setup` 操作；工具名、原分页和摘要保持兼容。检查新增稳定问题代码、对象列表和分组 ID。

## 实际浏览器验收

浏览器通过 CDP 连接操作隔离 SQLite 服务（8017）及前端（5177）；最终保存、恢复、报价及拓扑回归使用固定生产构建。测试名称、价格、产品和知识不写入业务库。

1. 从产品新增配套、引用原文、确认关系；候选与数量未知仍能保存，不产生虚构数量。
2. 新建房间和系统，角色尚未建立时填写终端规模；预览后批量建立。修复首次操作缺少维护人／依据导致的校验错误，表单现在明确收集这两个字段。
3. 撤销整个批次、重做、再次建立相同角色、保存和刷新；角色不重复，草稿恢复一致。
4. 候选选型及配套型号均由用户选择；侧面板保持打开，单候选不会自动加入。缺少数量依据的需求保留待确认。
5. 从待办跳转知识并返回原草稿；旧包角色定义 v1 在当前定义 v2 存在时仍维持 v1，保存前显示差异。
6. 报价采用两项隔离测试价格：10.25 元及明确零价，合计 10.25 元；保存后生成设备清单和公司报价模板。
7. 生产构建继续修改图纸引用、撤销、重做、保存至 v5 并刷新，设备仍为两项、报价仍为 10.25 元，无浏览器错误日志。

开发期间热更新改变编辑器 Hook 布局后曾出现草稿版本冲突，界面明确显示冲突并保留本地状态，未覆盖服务端。重新从持久草稿打开固定生产构建，重复“保存后继续编辑”及图纸撤销重做通过；该现象没有被用自动覆盖或静默降级掩盖。
