## 0.1.1 部署与操作说明

先部署本轮服务端，再更新插件至 0.1.1，以支持新增未解析行、问题导航和匿名阶段耗时。插件资源和 API 继续使用相同内网 HTTPS 域名与 Bearer 鉴权，无新增外部上传。

问题入口导航到已有身份确认、模板来源、业务设置或固定知识详情；点击不会授权写入、确认知识或发布规则。涉及当前依赖的未知行需要解决；已证明无关的区域仅提示。正式同步仍检查完整工作簿，不能跳过未解析行。

IndexedDB 逐事件保存诊断。旧 localStorage 队列持久化并读回核对成功后才清理；失败在任务窗格显示，不影响产品事务，也不静默丢失或回退到同步队列。上传仍每批最多 50，服务端保留 30 天。令牌仍通过原 CredentialStore 持久化；不写入工作簿。

本轮仅沿用现有灰字浮层与统一 Tab 协调器，未扩建原生探针。接受、跨行预览、独立撤销、恢复及显式同步的原有保护保持。
