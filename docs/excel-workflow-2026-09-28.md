# Excel 用户清单编辑与导入

本轮接入已有报价的明细数据迁移、项目说明和表内编辑。沿用 Configuration、edit-preview、项目撤销及版本保存；不改变产品库资料，不增加依赖或模型服务。

## 如何使用

1. 打开项目的“报价与模板导出”，先设置本次报价资料。
2. 点击“导入 / 粘贴清单”。上传 `.xlsx`，或粘贴 Excel 表头和明细；直接往工作表粘贴较宽矩形区域也会打开核对入口。
3. 选择工作表、表头行、各业务字段对应列。表头行填 0 可导入不带表头的明细。单行分区标题会成为可编辑的分区建议。
4. 核对要导入的行、具体产品配置及资料来源、清单类型、数量、单位、单价、项目说明和备注。“采用唯一型号候选”仅在点击后填入唯一候选；同型号多版本或多来源继续人工选择。
5. 填写来源与价格依据，确认采用的单价符合本报价税运口径，检查后整批加入。原表金额和合计不会覆盖系统计算。
6. 保存项目后导出公司模板。每次整批加入只更新一次项目草稿，沿用统一撤销历史。

导入新增独立设备，初始部署量等于明确选中的采购量；不会把相同型号多行合并，不会自动推定房间、系统角色、共享或配套已满足。导入清单用于衔接选型检查，不能代替搭配知识确认。客户已有设备继续通过供货面板关联。

## 工作表直接编辑

- D 产品说明：仅修改本项目对外报价说明。原始参数仍在来源面板，可恢复原文。换型号或来源后，旧说明提示过期，当前展示新产品原资料，需重新确认。
- E 数量：修改本次采购量，先预览再应用。部署量、客户已有量及供货待定量保持不变，超量或未分配明确显示。
- G 单价：逐项或批量编辑，要求采用依据。
- J 备注：直接修改项目备注。自动检查提示及服务系统展示在业务面板，导出时仍附加到备注；避免把系统提示误写为人工备注。
- 型号、品牌、单位、金额与合计仍从产品来源或业务计算生成；换型使用产品候选面板。

导入空单价使用明确的 `import` 价格来源，保留缺价；不会因项目采用产品库价格列而自动补价。明确的 0 元单价与缺价分别处理。导入文件公式保留为文本，不运行公式；数量及单价公式需先转为已核对数值。

## 技术实现

- `POST /api/quotation/import-cells`：只读解析 XLSX 原始单元格，返回工作表供前端映射和核对，不保存文件、不写产品库。
- 业务操作新增 `purchase_set`、`description_set`，HTTP 与 MCP 共用编辑服务。新增价格来源 `import`，允许带依据的缺价。
- `Quotation.descriptions` 保存设备对应的项目说明及配置/来源绑定。报价导出使用项目说明，产品原始快照与设备清单原始规格保留。
- 导入通过已有 edit-preview 原子检查后更新草稿，不新增“导入后直接保存”分支。过期草稿、保存版本及过期检查结果不会覆盖后续修改。
- 采购编辑只替换该设备的采购分配，不消耗已有/待定分配。原业务检查继续报告超量。
- 无新依赖、数据库重建或迁移；旧项目没有 descriptions 时默认为空。
